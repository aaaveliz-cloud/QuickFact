==================================================
A. REGLAS DE TRABAJO
==================================================

Antes de realizar cambios:

1. Inspecciona todo el repositorio.
2. Lee README, package.json, configuración, Prisma, frontend y backend.
3. Determina exactamente qué está terminado.
4. Determina qué está incompleto.
5. Detecta errores de arquitectura.
6. Detecta problemas de seguridad.
7. Detecta problemas de multi-tenancy.
8. Detecta inconsistencias con esta especificación.
9. Conserva todo lo correcto.
10. Corrige únicamente lo necesario.

No asumas que una "fase" está terminada solamente porque existan archivos relacionados.

Comprueba que realmente funcione.

Después de cada fase:

- ejecutar build;
- ejecutar lint si existe;
- ejecutar typecheck si existe;
- ejecutar pruebas disponibles;
- corregir errores;
- verificar migraciones;
- verificar seguridad;
- verificar aislamiento multiempresa;
- verificar que no se rompieron funciones anteriores.

Haz commits pequeños y descriptivos cuando corresponda.

==================================================

Debe ser MULTIEMPRESA / MULTI-TENANT.

Cada empresa tendrá independientemente:

- RUC

- logo
